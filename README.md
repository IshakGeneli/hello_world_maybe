# Hello World (Flutter)

Basit bir Flutter uygulaması: "Merhaba Dünya" yazısı ve sayaç butonu.

## Derleme

APK otomatik derlenmez; sadece elle başlatılınca derlenir ve **Releases** bölümüne yüklenir.
Başlatmak için: Actions → "Android APK Derle" → Run workflow (istersen "test edilecekler" notunu yaz).

## Telefona kurma

1. GitHub uygulamasında veya tarayıcıda repo → **Releases** → en son build.
2. `app-release.apk` dosyasını indir.
3. Aç ve kur (ilk seferde "bilinmeyen kaynaklardan yükleme" izni istenir).
